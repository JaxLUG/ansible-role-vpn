# JaxLUG™ Ansible vpn Role

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg?style=plastic)](https://github.com/JaxLUG/ansible-role-vpn/blob/master/LICENSE.txt)

This repository is part of the official Jacksonville, Florida, Jacksonville
Linux Users Group™ community Ansible Config Project (ACP).

This the JaxLUG's ansible role common to any Gentoo Linux system that
requires secure communication over a VPN using Tinc. This role is donated
from William L. Thomson Jr., artifact from his past business, and he retains
co-licensing and ownership.

This is an initial work-in-progress community contribution, anyone is
welcome to participate and/or use.
